Once upon a time

Luma lived in a crowded chat booth. Answers arrived like paper airplanes and blew away. The booth could talk. It could not do.

A chat box answers once and forgets. A working AI system keeps context, uses tools, and turns a request into finished work.

The folded note — Prompts

A well-folded note names the job, the audience, the constraints, and what done looks like.

A prompt is the instruction. Prompt engineering is writing it so the job is hard to misread. Context engineering is choosing what else rides with the ask.

Library lion — LLM

Leo has read so many stories he can start almost any one. A plan is still only words until someone packs the picnic.

An LLM is a general-purpose thinking engine. By itself it does not fetch calendars, open files, or finish work.

Serving kitchen — vLLM

Leo is the cook. Vee is the kitchen that serves many plates at once.

vLLM is software that serves large models quickly to many users.

Pocket mouse — SLM

Scout does not know every story in the mountain. She knows the path right here.

An SLM is a compact model: good, fast, and nearby.

Neighborhood shopkeeper — SDM

Dom sells only maps of this neighborhood. Narrow on purpose. Sharp on purpose.

An SDM is a specialized domain model for one kind of work.

The backpack — Agents

An agent does not only answer. It acts: look something up, write a file, check the result, try again.

An agent is a model plus permission to use tools, running until the job is done or a person must step in.

Recipe shelf — Skills

You do not memorize every recipe. You open the right folder when the job matches.

Skills are reusable playbooks an agent can load on demand.

Safety rigging — Harnesses

The lion is strong. The harness keeps the strength useful.

A harness is the runtime around an agent: tools, permissions, logs, budgets, and stop rules.

Universal dock — MCP

Before MCP every tool spoke a private language. Now a dock is a dock.

MCP is a standard way to connect models to tools and data sources.

Garden path — Loops

THINK · ACT · LOOK · AGAIN. Not forever. Until the basket is ready.

A loop is reason → act → observe → decide. Loop engineering is when to continue, retry, ask, or stop.

Field glossary

Prompt
The instruction — job, constraints, format, definition of done.
Context engineering
What else rides with the prompt: files, history, retrieved facts.
LLM / SLM / SDM
Large, small, or specialized-domain models.
vLLM
High-throughput serving for large models.
Agent
Model + tools + loop that acts toward a goal.
Skill
Reusable playbook loaded when the task matches.
Harness
Runtime: tools, memory, permissions, stop rules.
MCP
Model Context Protocol for tools and data.
RAG
Fetch facts, then answer.
Human-in-the-loop
A person approves high-impact steps.
